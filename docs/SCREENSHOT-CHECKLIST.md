# Portfolio evidence checklist

Capture these screenshots after you have completed the lab:

- [ ] Hypervisor view showing DC01 and CLIENT01 (hide personal host details).
- [ ] Server Manager showing the AD DS role installed.
- [ ] Active Directory Users and Computers showing the Company OU hierarchy.
- [ ] Demo users and their security group memberships.
- [ ] Group Policy Management showing the workstation GPO linked to the Workstations OU.
- [ ] CLIENT01 showing successful domain membership.
- [ ] Successful `nslookup corp.example.test`.
- [ ] `dcdiag` output showing the results of domain-controller diagnostics.

## Before publishing

Inspect every screenshot. Remove passwords, recovery keys, license keys, public IP addresses, personal usernames, machine identifiers, and unrelated personal information.

Only include screenshots from a lab you actually built and tested. Do not present planned or sample configurations as completed work.
