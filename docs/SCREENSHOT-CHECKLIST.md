# Portföy için ekran görüntüleri

Kurulumu tamamladıkça aşağıdaki ekran görüntülerini ekleyeceğim:

- [ ] VMware'de DC01 ve CLIENT01 makinelerinin görünümü
- [ ] Server Manager'da AD DS rolünün kurulu olduğunu gösteren ekran
- [ ] Active Directory Users and Computers içindeki OU yapısı
- [ ] Örnek kullanıcılar ve grup üyelikleri
- [ ] Group Policy Management ekranında istemcilere bağlı GPO
- [ ] CLIENT01'in etki alanına başarıyla katıldığını gösteren ekran
- [ ] `nslookup corp.example.test` komutunun sonucu
- [ ] `dcdiag` kontrolünün sonucu

## GitHub'a koymadan önce

Ekran görüntülerinde parola, lisans anahtarı, kişisel kullanıcı adı, gerçek IP adresi veya özel bilgilerin görünmediğini kontrol et.

Yalnızca kendi kurduğum ve test ettiğim ortamdan görüntü ekleyeceğim. Henüz yapmadığım bir işlemi tamamlanmış gibi göstermeyeceğim.
